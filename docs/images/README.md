# Images

Screenshots, GIFs and diagrams used by the READMEs and docs. Suggested set to add:

- `studio.png`: the formula editor with the validation panel showing a few checks
- `batch.png`: the batch screen or bench mode
- `community.png`: the community feed
- `demo.gif` (under about 5 MB): a short flow, such as building a formula and fixing a warning

Reference them from the root README with a relative path, for example `![The formula studio](docs/images/studio.png)`.
